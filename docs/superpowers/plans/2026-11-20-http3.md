# HTTP/3 for clients: Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** RXH serves HTTP/3 on every `http` server with TLS, advertises it with `Alt-Svc`, and keeps QUIC connections alive across reloads.

**Architecture:** A generation builds, per HTTP/3 address, an `http3::Listener`: plain shared data (routes, limits, log, QUIC TLS configuration). The daemon owns `http3::Endpoints`, a map from listen address to a `quinn::Endpoint` that outlives generations and runs on the daemon's runtime in both `shared` and `per_core` modes. Installing a generation swaps the `Listener` each endpoint hands new connections to; open connections keep the `Listener` they were accepted under and that generation's stop drains them.

**Tech Stack:** `quinn` 0.11 (rustls 0.23 with `aws-lc-rs`, tokio runtime), `h3` 0.0.8, `h3-quinn` 0.0.10, `socket2` 0.6 (already in `Cargo.lock`) for `SO_REUSEPORT` on the UDP socket.

**Spec:** `docs/superpowers/specs/2026-11-20-http3-design.md`

## Review Focus

1. Client resets a request stream mid-body: the backend request is cancelled and the connection's `max_connections` permit and in-flight count are not leaked. Test in Task 3.
2. Backend dies mid-response: the HTTP/3 stream is reset, never finished cleanly as if the body were complete. Test in Task 3.
3. `HEAD`, `204` and `304` responses: no body bytes on the stream, `content-length` of a `HEAD` response kept. Test in Task 3.
4. Routing by host: an HTTP/3 request has `:authority` and no `Host` header; virtual hosts must still match. Test in Task 3.
5. Listen address `[::]:port`: the UDP socket binds the same family and address as the TCP listener. Test in Task 4.

```rust
/// QUIC flavour of the configuration `acceptor` builds for the same
/// `servers`: same provider, client verifier and `resolver`; TLS 1.3 only,
/// ALPN `h3`, no early data.
pub(crate) fn quic_config(
    servers: &[&config::Server],
    resolver: &Arc<CertResolver>,
) -> io::Result<Arc<rustls::ServerConfig>>;

// http3.rs
/// What one generation serves over HTTP/3 on one address.
pub(crate) struct Listener { /* address, required, tls, context: Arc<ConnectionContext>,
                                permits: Arc<Semaphore>, phase, open, active */ }
impl Listener {
    pub(crate) fn address(&self) -> SocketAddr;
    /// `h3=":<port>"; ma=86400` while an endpoint serves this listener.
    pub(crate) fn alt_svc(&self) -> Option<HeaderValue>;      // used in Task 5
    /// GOAWAY to every connection, wait for them within `grace`, then close them.
    pub(crate) async fn drain(&self, grace: Option<Duration>); // used in Task 4
}

/// QUIC endpoints of the daemon, by listen address. They outlive generations.
pub(crate) struct Endpoints { /* Mutex<HashMap<SocketAddr, Entry>> */ }
impl Endpoints {
    pub(crate) fn new() -> Self;
    /// Makes `listeners` the ones new connections are served by. Binds the
    /// addresses that have no endpoint yet.
    pub(crate) fn install(&self, listeners: &[Arc<Listener>]) -> Result<(), Error>;
}

// master.rs
pub struct ServerInfo { /* … */ pub(crate) http3: Option<Arc<http3::Listener>> }

// crates/util/src/http3_client.rs
pub struct Http3Client;            // one QUIC connection
pub struct Http3Response { pub status: StatusCode, pub headers: HeaderMap,
                           pub body: Bytes, pub trailers: Option<HeaderMap> }
impl Http3Client {
    /// Trusts `root_pem`; presents `identity` (certificate chain PEM, key PEM) if given.
    pub async fn connect(address: SocketAddr, server_name: &str, root_pem: &str,
                         identity: Option<(&str, &str)>) -> io::Result<Self>;
    pub async fn send(&mut self, request: Request<Bytes>) -> io::Result<Http3Response>;
    /// Sends the head and `partial` body bytes, then resets the stream.
    pub async fn send_and_reset(&mut self, request: Request<()>, partial: &[u8]) -> io::Result<()>;
    /// Resolves when the server closes the connection.
    pub async fn closed(&self);
}
```

**Decisions:**
- `Server::init` builds the `Listener` only when `server.serves_http3()` (first member decides) and never in `from_replica`. It reuses the `Arc<ConnectionContext>` and the `permits` of the TCP listener, so limits and logs are shared. Make the items `http3.rs` needs `pub(crate)`.
- `ServerInfo.http3` carries it out of `Master::init`; `per_core::Started.servers` already carries `ServerInfo`. `Generation::start` gets `&Endpoints` and calls `endpoints.install(…)` as its **last fallible step**. `Daemon` creates one `Endpoints` in `run` and passes it to every `Generation::start` call (there are four).
- Socket: `systemd::udp_socket(address)` first; else `socket2` socket, same family as `address`, `SO_REUSEPORT` on unix, IPv6-only when the address is IPv6, non-blocking, then `quinn::Endpoint::new(EndpointConfig::default(), Some(server_config), socket, Arc::new(TokioRuntime))`.
- `install` on an address that already has an endpoint: `endpoint.set_server_config(Some(…))` and swap the current `Arc<Listener>` (a `watch` channel read by the accept loop). The accept loop is spawned once per endpoint, on the runtime `install` is called from.
- In this task an install replaces the whole set but **does not** retire, drain or handle bind errors specially: any bind error is returned. Tasks 4 and 5 own those.
- Per connection: `Service` built as `handle_connection` does (`peer`, `peer_ip`, `local = listener address`, own `Activity`, `client_subject = None` for now), one task per request stream calling `service.respond(request)`. Requests get `Version::HTTP_3`.
- Request body: a `Body` fed by the receive half of the stream (data frames, then trailers). Errors map to `BodyError::Io`. A bounded channel of capacity 1 between a reader task and the body is enough.
- Response: head, each data frame, trailers, then finish. Remove `connection`, `keep-alive`, `proxy-connection`, `transfer-encoding` and `upgrade` from the response head. A body error resets the stream with `H3_INTERNAL_ERROR`. A client reset drops the response future.
- QUIC transport parameters: library defaults.

### Task 4: Limits, timeouts, mutual TLS, lifecycle

**Files:**
- Modify: `crates/server/src/http3.rs`, `server.rs` (`Server::run` shutdown, lines ~520-570), `daemon.rs` (`Generation::start`, shutdown path, upgrade handover near line 485)
- Test: `crates/server/tests/http3.rs`

**Interfaces:**
- Consumes: everything from Task 3.
- Produces:

```rust
impl Endpoints {
    /// Closes at once the endpoints on addresses `config` gives to a `udp` server.
    pub(crate) fn release(&self, config: &Config);
    /// Closes every endpoint at once: daemon stop and binary handover.
    pub(crate) fn close(&self);
}
```

**Decisions:**
- **Connection limits.** Before the handshake completes, take a permit with `try_acquire_owned` on the shared semaphore and a `PerIpSlot`; refuse the incoming connection (`Incoming::refuse`) when either is unavailable. Never wait for a permit: a QUIC client retries on TCP.
- **`idle_timeout`** → `TransportConfig::max_idle_timeout`. Unset → quinn default.
- **`read_header_timeout`** (default `DEFAULT_READ_HEADER_TIMEOUT` in `server.rs`): a connection with no complete request head in that time after the handshake is closed with `H3_NO_ERROR`.
- **`client_auth`**: the subject of the peer certificate (`Connection::peer_identity`, downcast to `Vec<CertificateDer>`) goes through the same function the TCP path uses to fill `Service::client_subject`.
- **Drain.** `Listener` holds a `watch::Sender<Phase>` (`Serving`, `Draining`, `Closed`) and a count of open connections. `drain(grace)`: send `Draining` (each connection sends GOAWAY and stops accepting streams), wait for zero open connections within `grace` (`None` waits forever), then send `Closed` (each connection closes with `H3_NO_ERROR`) and wait for zero. `Server::run` calls it in its shutdown branch, concurrently with the TCP drain and under the same `grace_period`.
- **Install, completed.** Addresses with an endpoint but no listener in the new set are retired: `set_server_config(None)`, entry removed from the map, a task awaits `endpoint.wait_idle()` and drops it. The old generation's drain empties it.
- **`release`** is called in `Generation::start` before `Master::init`, like `acme::release_challenge_port`.
- **`close`** is called when the daemon stops, after the generation's stop, and in the old process at binary handover, right after the new process reports ready and before the old generation's graceful stop. The UDP socket is not leased to the new process.

**Decisions:**
- `Listener.active` is set by `install` once an endpoint serves the listener and cleared when it is retired or closed. `alt_svc()` returns `None` while inactive. The port is the listener address port.
